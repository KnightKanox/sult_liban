# 网页阅读

> 读取并解析指定 `URL` 的网页内容，可选择返回格式、支持控制缓存、图片保留与摘要选项等。点击 **Try it** 按钮可快速试用。

      `memory_store_enabled=true` 时，Forward 为私聊用户或群创建并挂载长期 Memory Store；群主线与各

      result，调用者需通过 Managed Session API 完成交互。
